# 🚀 Typing Lab — Potencia tu Mecanografía con IA

**Typing Lab** es una aplicación web de última generación diseñada para llevar tus habilidades de mecanografía al siguiente nivel. Con un diseño premium basado en *glassmorphism*, una mascota reactiva impulsada por diferentes personalidades y un currículo global, es la herramienta definitiva para aprender a teclear con velocidad y precisión.

![Typing Lab Banner](https://images.unsplash.com/photo-1587829741301-dc798b83aca2?ixlib=rb-4.0.3&auto=format&fit=crop&w=1200&q=80)

## ✨ Características Principales

### 🌍 Soporte Multi-idioma Real
No solo traducimos la interfaz, adaptamos tu experiencia de aprendizaje a **8 idiomas** y sus disposiciones físicas de teclado:
- **Español (ES)** - QWERTY con Ñ.
- **English (EN)** - QWERTY estándar.
- **Galego (GL)**, **Català (CA)**, **Euskara (EU)** - Con caracteres especiales como `ç`, `l·l`, etc.
- **Français (FR)** - Layout **AZERTY** completo.
- **Deutsch (DE)** - Layout **QWERTZ** con `Ä, Ö, Ü, ß`.
- **Português (PT)** - Con foco en cedillas y tildes nasales.

### 📚 Currículo Progresivo de 20 Niveles
Cada idioma cuenta con un plan de estudios de **20 lecciones únicas** que te guiarán desde la fila central hasta textos complejos y pangramas de maestría.

### 🤖 Cybot: Tu Mentor IA
Nuestra mascota reactiva, **Cybot**, te acompaña en cada pulsación. Elige su estilo:
- **Neon:** Enérgico y motivador.
- **Zen:** Calma tu mente y fluye con el tecleo.
- **Sarcástico:** Te retará con humor ácido si cometes errores.

### 🔓 Modo Libre (PRACTICA LO QUE QUIERAS)
¿Tienes que estudiar un tema o practicar un código específico? Pégalo en el **Modo Libre** y Typing Lab lo convertirá instantáneamente en una sesión de práctica con seguimiento de errores y velocidad.

### 📊 Estadísticas en Tiempo Real
- **PPM (Palabras por Minuto):** Brutas y Netas (ajustadas por error).
- **Precisión:** Porcentaje exacto de acierto.
- **Racha (Combos):** Indicadores visuales de fluidez.
- **Mapa de Errores:** Identifica qué teclas son tu "punto débil" al final de cada sesión.

## 🛠️ Tecnologías Utilizadas

- **Vite:** Para un desarrollo ultrarrápido.
- **JavaScript (ES6+):** Lógica modular y gestión de estados dinámica.
- **CSS Avanzado:** Glassmorphism, animaciones 60fps y diseño 100% responsivo.
- **HTML5:** Estructura semántica ideal para accesibilidad.

## 🚀 Instalación y Ejecución

Si deseas clonar y ejecutar este proyecto localmente:

1. **Clonar el repositorio:**
   ```bash
   git clone [url-del-repo]
   ```

2. **Entrar al directorio:**
   ```bash
   cd tecleador
   ```

3. **Instalar dependencias:**
   ```bash
   npm install
   ```

4. **Ejecutar en modo desarrollo:**
   ```bash
   npm run dev
   ```

5. **Abrir en el navegador:**
   Visita `http://localhost:5173`

## 📂 Estructura del Proyecto

- `index.html`: Punto de entrada y contenedor principal.
- `src/main.js`: Corazón de la app. Gestiona los 8 idiomas, las 160 lecciones totales, la lógica del teclado y el cronómetro.
- `src/style.css`: Estilos visuales, temas dinámicos y animaciones de la mascota.
